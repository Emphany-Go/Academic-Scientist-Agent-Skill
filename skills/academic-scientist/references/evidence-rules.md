# 证据与真实性规则 v0.1.0

## 四种来源

论文事实使用 `source_kind=provided_document`。期刊资料、Agent 分析、用户观点在后续各自的记录类型中保存，本阶段事实 schema 不接受这些来源。用户提供的附录/补充文件要独立登记 source_id；未提供的引用论文不能当已读。

## 字段状态

| 状态 | 值 | 条件 |
|---|---|---|
| supported | 非空 | 原文直接支持、忠实概括或有证据的类别映射；有证据 ID |
| not_reported | null | 已检查可能承载该信息的全部已提供相关内容，且解析足以支持这一判断；必须保存搜索/阅读覆盖说明 |
| uncertain | null | 原文含糊、冲突、缺相关材料或解析失败；原因必填。model_origin 可用 [undetermined] |
| not_applicable | null | 该概念不适用；依据与理由必填，不因没找到就选此项 |
| not_checked | null | 尚未检查；绝不能混入“已完成抽取” |

每个字段另有 review_status：unreviewed / agent_checked / human_checked。它记录谁核对过，不是正确概率。没有实际人类核查不得用 human_checked。

## 定位与表示

- PDF 保存 1 起始物理页码；若需印刷页码另存 printed_page，不互相替换。
- 文本材料可用行号范围；表格注明 table 标识、行和列；图示注明 figure、子图和标签。
- text/table 证据保存原文短片段或表头与单元格转写，不把中文翻译冒称英文原文。
- figure 证据只作明确可见标签/结构的文字转写并保留裁图路径（若有）；图注不足以证明图内数值。
- 没有标明数值的曲线不得用肉眼估计后写为报告值；本阶段不提供图像数字化工具。
- 支持一个字段可能需要多处证据；结果要结合表头、行、单位和方法设置，不只摘孤立数值。
- 仪器、计算模型、实验对象分清；作者结论、引用工作、基线的归属不能错配。

## 复核顺序

1. 原文位置是否存在，source_id 是否对应当前论文的给定材料。
2. 原文是否支持 value 的每一项，不能只支持其中一部分。
3. 比较值与绝对值、相关与因果、可行与已证明、声明提供与实际可访问是否被混淆。
4. 数值、单位、有效位数、上下界、数据/材料体系和实验条件是否一致。
5. 无法确定时转 uncertain；保留冲突证据，不自行挑更符合预期的一条。

第一次提取与复核是不同操作，同一个 Agent 复核也不算独立验证。结构校验器只能发现格式/引用/状态错误，不能证明段落真实存在或支持结论。真实性评测必须回到 PDF/原始材料。

## 覆盖度与失败

文档 coverage 保存已检查物理页、缺失或不可读页及附件缺失。字段 not_reported 还需 checked_scope；不能用全文级“完成”代替每个字段检查。

记录可为 partial；只读首页也可提交部分记录，但其他字段须 not_checked。完整记录要求所有论文层字段有状态、实际模型与实验已覆盖，且解析遗漏已报告。自动检查不能验证是否遗漏了整组模型/实验，由人工覆盖评测补充。

用户修订不能悄悄删除原值与证据。修订有原文支持才可成为核查后的事实；个人解释独立记录。文档更新后旧证据须重新定位，不能复用可能错位的页码。
