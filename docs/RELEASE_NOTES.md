# Academic-Scientist Agent Skill V0.1

首次正式本地skill发布，许可证MIT。内部skill名保持academic-scientist。发布版本号不改写已有事实/会话/方案Schema版本。

## 包含的能力

研究探索、PDF接收、候选抽取与逐项复核、官方平台认知卡、可编辑文献表与修订、有依据的学习建议、单路线研究方案和三类可编辑图。延续不量化推荐、不虚构用户回复、不联网回填论文事实、不执行实验等规则。

复杂图以最终draw.io XML为源，固定端口和折点并检查穿框；SVG由同一XML生成。新研究项目采用简洁成果目录与内部证据/状态分层。新渲染的浏览器临时目录在关闭后清理；必要审阅截图和历史保留。提供环境检查、非覆盖安装器和包校验工具。

## 验证范围

详见根目录VALIDATION.md。开发回归、打包完整性、隔离安装、渲染及清理验证分别记录。用户此前已确认真实测试中的三轮讨论/抽取分析基本符合预期，并反馈连线修复图已没有此前问题；这不是全字段准确率或跨平台完整验收。

## 已知限制

- 仍需Codex完成语义阅读/判断和官方查询；脚本不是独立科研Agent服务。
- Excel依赖宿主现有@oai/artifact-tool；绘图预览依赖Node/Playwright/Chrome，安装包不携带运行库。
- PDF解析不含自动OCR；复杂图表仍需实际视觉核对。没有测得完整正确率/覆盖率或全流程成本统计。
- 已完成本地XML/SVG/PNG/PDF检查；原生draw.io应用内打开/拖动兼容未独立验证，不声明camera-ready。
- 内置预览采用受限文字排版，过长英文可能按字符换行；需按实际截图手动分行或加宽节点，不直接视为投稿版式。
- 历史评测中方向变更及真实Excel冲突等场景尚未全部完成独立用户验收；代码回归测试不能代替它们。
- 旧研究目录不自动迁移；用户编辑的表层文件需要明确协调后才替换。历史证据不自动裁剪，磁盘占用随研究增长。
- 发布验证使用Windows与已有运行环境；未独立验证macOS/Linux或所有Codex客户端。
